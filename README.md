# 楠梓吃什麼

高雄市楠梓區美食清單，做成可離線使用的一頁式 Web App。

資料來自 23 篇 Threads 貼文（含留言區補充），**地址與營業時間逐家對過 Google 地圖**，
查證日 2026-09-07。小吃店異動快，出發前請按卡片上的「開地圖導航」以 Google 地圖的即時狀態為準。

## 功能

- 27 家店，含價位分級、食物種類、時段標籤、一週營業時間（含公休日）
- 依店名／菜色／路名搜尋，可依時段、價位、種類篩選
- 「營業中」以**台北時間**即時計算，跨夜營業（到凌晨 1 點那種）也算得對
- 一鍵開 Google 地圖導航、一鍵回 Threads 原文
- ★想吃／✓吃過（存在瀏覽器本機）
- 支援深色模式；資料滿 180 天會自動跳出過期提醒
- PWA：可加到手機主畫面，離線可用

## 部署

純靜態，沒有建置步驟。GitHub Pages 開 `main` 分支根目錄即可。

本機預覽（Service Worker 需要 http，直接開 file:// 不會註冊）：

    python3 -m http.server 8000

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App，資料內嵌其中 |
| `sw.js` | 離線快取；改版時把 `VERSION` 加一 |
| `manifest.webmanifest` | 主畫面圖示與 App 名稱 |
| `data/` | 原始 Threads 連結與整理筆記 |

## 更新資料

店家資料寫在 `index.html` 裡的 `const D = [...]`，每筆的 `h` 是
週日到週六的營業區間，單位為「當日零點起算的分鐘數」，跨夜用大於 1440 表示
（例如 `[1020,1530]` = 17:00–翌日 01:30）。
